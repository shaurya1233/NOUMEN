## Versioning Policy

This repository follows a simple semantic versioning approach:

- **MAJOR:** Significant structural or compatibility changes.
- **MINOR:** New functionality or substantial additions.
- **PATCH:** Small corrections, refinements and fixes.

## Change Documentation Policy

Future changes should be documented under the appropriate version
and date.

Each entry should distinguish between:

- Added — New files or functionality.
- Changed — Modifications to existing resources.
- Fixed — Corrections and bug fixes.
- Removed — Deleted or discontinued resources.
- Security — Security-related improvements.

Only document changes that have actually been made and verified.
